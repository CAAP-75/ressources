CHANGER LES PHOTOS DE LA PWA
============================

La PWA a été préparée pour que les photos puissent être changées très facilement.

MÉTHODE LA PLUS SIMPLE
----------------------
1. Ouvrir le dossier : assets
2. Remplacer l'image souhaitée par votre nouvelle photo.
3. Conserver EXACTEMENT le même nom de fichier.
4. Envoyer les fichiers modifiés sur GitHub.

AUTRE POSSIBILITÉ
-----------------
Le fichier photos.js centralise tous les chemins des images.
Vous pouvez y remplacer un chemin local par une autre image ou par une URL https://...

CONSEILS
--------
- Miniatures : format paysage 16:9 ou proche, idéalement 1200 x 675 px.
- Bandeau : conserver les proportions du fichier hero-home.png (environ 2,55:1).
- Formats conseillés : JPG pour les photos, PNG pour les visuels avec texte/logo.
