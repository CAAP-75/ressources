COLLÈGE ACTIF, AVENIR POSITIF — GUIDE DES PHOTOS
=================================================

Le principe est volontairement simple :
- toutes les photos sont dans le dossier assets/
- le fichier photos.js indique quelle image est utilisée à quel endroit
- vous pouvez remplacer une photo en conservant exactement le même nom de fichier

2. LES SUJETS / RUBRIQUES
-------------------------
Les miniatures des sujets utilisent les images définies dans SECTION_PHOTOS du fichier photos.js.
Vous pouvez changer le fichier indiqué ou modifier son chemin.

3. UNE PHOTO DIFFÉRENTE POUR UN ARTICLE PRÉCIS
----------------------------------------------
Dans photos.js, ajoutez le titre EXACT de la ressource dans RESOURCE_PHOTOS.

Exemple :
RESOURCE_PHOTOS: {
  'Cohérence cardiaque': 'assets/coherence-cardiaque.jpg',
  'Prêts de vélos aux personnels': 'assets/velos-personnels.jpg'
}

Il suffit ensuite de déposer les images coherence-cardiaque.jpg et velos-personnels.jpg dans assets/.
