PWA — COLLÈGE ACTIF, AVENIR POSITIF
Version 5 — interface simplifiée

Cette version propose :
- un bandeau d'accueil conservé dans ses proportions d'origine ;
- le logo officiel de l'Académie de Paris en haut à gauche ;
- 8 grandes entrées seulement, avec titre + sous-titre + photo ;
- une navigation directe : grande entrée → contenus ;
- des sous-rubriques discrètes utilisées comme intertitres, et non comme nouvelles cartes ;
- des ressources compactes avec petites miniatures ;
- des favoris ;
- « Je cherche une idée » ;
- un système de photos modifiables dans photos.js ;
- le PDF source complet du Padlet ;
- la possibilité de connecter ultérieurement un flux Google Drive via config.js / Google Apps Script.

MISE EN LIGNE GITHUB PAGES
1. Décompresser le ZIP.
2. Déposer tout le contenu du dossier caap_pwa_v5 à la racine du dépôt GitHub.
3. Dans GitHub : Settings > Pages > Deploy from a branch > main / root.
4. Attendre la publication puis ouvrir l'URL GitHub Pages.
5. Si une ancienne version reste affichée, vider le cache du site ou ouvrir une fenêtre privée une première fois.

Pour changer les photos : lire GUIDE-PHOTOS.txt.
