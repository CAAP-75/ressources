PWA « Collège actif, avenir positif » — V10

Évolutions de cette version :
- Les 7 entrées « Je veux… » sont placées directement sur la page d’accueil, sous le bandeau.
- Les icônes ont été supprimées devant les intitulés « Je veux… ».
- « Je cherche une idée » reste visible sur l’accueil.
- La page Ressources ne présente plus de cartes de navigation : uniquement les ressources.
- Les miniatures ont été supprimées de la page Ressources.
- Les titres des ressources sont agrandis et mis en avant.
- Les couleurs des rubriques sont harmonisées entre Accueil et Ressources.
- Un clic sur une entrée « Je veux… » ouvre la page Ressources filtrée sur ce besoin.
- Le menu Ressources affiche toutes les ressources classées par besoin.

Pour la mise en ligne GitHub Pages, déposer l’ensemble des fichiers du dossier à la racine du dépôt.
